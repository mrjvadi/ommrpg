# CHARACTER_SYSTEM.md

## Visible
- level
- attributes
- energies
- knowledge
- understanding
- mastery
- class
- profession
- inventory
- equipment
- reputation
- achievements

## Hidden
- Root
- innate talent
- hidden affinity
- latent potential
- learning bias
- creation bias
- discovery bias
- class path bias

## Root
Examples:
- Starforged
- Voidborn
- Soul Weaver
- Spirit Vessel
- Beast Heart

## Talent
Examples:
- Perfect Synthesis
- Spatial Affinity
- Blacksmith Precision
- Alchemy Talent

## Effects
Hidden potential may influence:
- learning speed
- mastery growth
- crafting quality
- fusion compatibility
- discovery probability
- energy compatibility
- class eligibility

## Energies
Examples:
- physical
- spiritual
- mental
- life
- soul
- arcane
- void

Each energy has capacity, recovery, compatibility and possible side effects.

## Class
Class is not selected at the beginning.
Class awakens after Level 10 using accumulated evidence.

## Profession
Profession is separate from Class.
Example:
Class = Necromancer
Profession = Blacksmith
Secondary = Herbalist

## Hidden Path
An unusual combination may awaken a rare or unique path.

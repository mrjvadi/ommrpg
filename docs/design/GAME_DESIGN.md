# GAME_DESIGN.md

## Vision
Build a living MMO where players and persistent AI residents create history.

## Character Experience
Players should feel that the character grows because of their actions, choices,
teachers, discoveries, relationships and environment, not simply because of XP.

## Core Loop
Explore -> Learn -> Understand -> Practice -> Master -> Discover -> Create -> Trade ->
Join/Build City -> Participate in Kingdom -> Politics/War -> Ascend -> New World -> Legacy.

## Non-Combat Progression
A player can be valuable as:
- merchant
- teacher
- alchemist
- blacksmith
- explorer
- scholar
- diplomat
- spy
- farmer
- formation specialist

## No Universal Best Build
Level is not the only source of power.
A low-level specialist can possess resources or knowledge a high-level character needs.

## Persistence
Major events must become part of world history:
- first discoveries
- first cities
- first gates
- major wars
- treaties
- world bosses
- unique creations
- class/path discoveries

## Design Goal
Create stories that emerge from systems, not from prewritten scripts only.

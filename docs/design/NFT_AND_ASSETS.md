# NFT_AND_ASSETS.md

## Philosophy
The game must remain fun and complete if blockchain market value becomes zero.

NFT/blockchain is an optional ownership/export layer.

## Possible Assets
- unique discoveries
- rare knowledge assets
- licenses
- unique artifacts
- rare cosmetics
- historical objects
- unique creatures where appropriate

## Ownership vs Mastery
Ownership of a Knowledge Asset does not transfer another character's mastery.

Example:
Asset owner = Raven
Raven mastery = 0%

## Licensing
Support:
- limited uses
- time limit
- student limit
- kingdom-only
- craft-only

## Historical Identity
Keep:
- first discoverer
- creator
- original owner
- current owner
- ownership history
- creation time
- location
- lineage

## Blockchain Boundary
Game database remains authoritative.
Blockchain service integrates with asset-service.
Never let blockchain override game rules.

## Monetization
Possible marketplace fees are configurable.
Do not make raw combat power directly purchasable.
